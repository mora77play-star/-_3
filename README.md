# قالب رفيق الأذكار

قالب Flutter حديث لتطبيق أذكار متكامل بواجهة عربية هادئة ووظائف محلية جاهزة للتوسعة.

## المزايا
- أذكار الصباح والمساء والنوم وبعد الصلاة.
- نصوص منقحة مع نسبة المصدر ورقم الحديث عند توفره.
- عداد تكرار مستقل لكل ذكر مع شريط تقدم.
- فصل تسبيح المائة «سبحان الله وبحمده» عن حديث «كلمتان خفيفتان» ذي العدد المفتوح.
- المفضلة والبحث والتصفية.
- حفظ التقدم محليًا عبر SharedPreferences.
- الوضع الداكن.
- بنية Android حديثة مطابقة للمرجع.

## ملاحظة علمية
- ذكر الصباح والمساء الطويل من صحيح مسلم (2723)، وقد استُخدمت صيغة الصباح وصيغة المساء بحسب الرواية.
- «رضيت بالله...» أصل الذكر ثابت في صحيح مسلم (1884)، أما تقييده بثلاث مرات فورد في أبي داود والترمذي والنسائي وأحمد، مع اختلاف أهل العلم في تصحيح هذه الرواية بعينها.
- «باسمك اللهم أموت وأحيا» في صحيح البخاري (6324).
- الاستغفار ثلاثًا بعد الصلاة في صحيح مسلم (591).
- «كلمتان خفيفتان...» متفق عليه، والعدد فيه مفتوح.
- «سبحان الله وبحمده» مائة مرة صباحًا ومساءً في صحيح مسلم (2692).

## الإصدارات
Flutter 3.47.2، Java 17، Gradle 8.14، Android Gradle Plugin 8.11.1، Kotlin 2.2.20، compileSdk وtargetSdk 36.
